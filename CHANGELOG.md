# Changelog

## Unreleased — 0.1.0 implementation candidate

- Portable 1.0.0 flow contract, semantic validation, safe local reader, and reference scenarios.
- Hierarchical React viewer with search, history, stable positions, source evidence,
  responsive details, and public before/after and scale samples.
- Downloadable existing-agent kit, additive maintenance instructions, recovery prompts,
  standalone validation, and exact source/map review receipts.
- Read-only GitHub App sign-in, selected-repository authorization, encrypted sessions,
  browser onboarding, disconnect, and local account deletion.
- Immutable branch snapshots, explicit freshness/coverage, labeled fallback, safe
  degraded sections, and stable-identity PR comparisons.
- Automated contract, agent, authorization, privacy, snapshot, scale, and browser checks.
- MIT license, user/contributor/operator/security documentation, and explicit external
  acceptance gates. No live service deployment or certified agent integration is claimed.

The map format remains 1.0.0. Unsupported versions fail closed; there is no migration
that simply changes the version string. Future incompatible changes require an
explicit migration tool and compatibility notes before release.
